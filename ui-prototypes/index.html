Jipsa 가계부 · UI 후보

같은 더미데이터(2026년 6~11월, 약 480건)로 만든 세 가지 방향입니다. 지출 종류(일반 지출 / 고정비 / 할부), 카테고리, 태그를 모두 반영했어요.

📊
후보 A

대시보드형

사이드바 + KPI 카드 + 차트 + 거래 테이블. 한 화면에서 이번 달 상태와 내역을 모두 봅니다.

  • 가장 익숙하고 확장하기 쉬움
  • 태그 클릭 → 내역 필터, 지출 추가 모달 포함
  • 정보 밀도가 높아 "패턴"이 덜 도드라짐
📅
후보 B

캘린더형

월 달력이 메인. 날짜별 지출 강도, 고정비·할부 결제일, 남은 고정 지출 일정을 한눈에.

  • 입력·확인이 일상적으로 편함 (자연어 빠른 입력)
  • 태그/종류 하이라이트로 "언제" 쓰는지 보임
  • 월 간 비교 분석은 약함 → 별도 분석 탭 필요
📈
후보 C

패턴 리포트형

자동 인사이트 문장, 카테고리×월 히트맵, 요일 패턴, 태그 증감, 약정 지출 전망.

  • "월별 소비 패턴 분석" 목적에 가장 직접적
  • 할부 종료 시점까지 미래 전망 제공
  • 입력/내역 관리 화면은 따로 필요
추천 조합 — 실제 앱은 하나만 고르기보다 B(캘린더) = 기록/일상 화면, C(리포트) = 분석 화면으로 탭을 나누고, A의 거래 테이블·추가 모달을 공통 컴포넌트로 쓰는 구성이 목적(월별 패턴 분석)에 잘 맞습니다.
데이터 모델 — 더미데이터는 { date, amount, merchant, kind: general|fixed|installment, category, tags[], card, installment?: { current, total, principal } } 구조입니다. 공통 파일: data.js
